# سهرة طلقة — نسخة مصرية من لعبة سهرات جماعية

لعبة سهرة جماعية: شاشة كبيرة (لابتوب/تلفزيون) بتدير السهرة، وكل واحد بيلعب من موبايله بالكود أو الـQR.
فيها لعبتين زي الأصل بالظبط في الشكل والسلوك:

- **بارتي ميكس**: ٣٠ لعبة صغيرة (سرعة، مخ، اجتماعية، فوضى)، ٣ مستويات (خفيف/متوسط/تقيل)، روليت مفاجأة، مهمات سرية، وحفلة من غير مشروبات.
- **المركب**: لعبة الكوتشينة بخمس جولات (أحمر ولا إسود، أعلى ولا أوطى، جوه ولا برة، الهرم، المركب).

كل حاجة ظاهرة باللهجة المصرية، والواجهة RTL. محتوى الأسئلة اتعمل من الأول لمصر (أكل، أفلام، كورة، أماكن…).

> ده مشروع مستقل جوه الريبو. ما بيغيّرش أي حاجة في مشروع `app/` أو `dashboard/`.

## التشغيل محليًا

محتاج Node 20 أو أحدث.

```bash
cd masr-party
npm install
npm run build      # يبني الواجهة في client/dist
npm start          # السيرفر على http://localhost:8787
```

- افتح `http://localhost:8787` على لابتوب ← «يلا نبدأ الحفلة» ← «افتح الحفلة 📺».
- من الموبايلات (على نفس الشبكة): اعمل سكان للـQR، أو افتح `http://<IP-اللابتوب>:8787` واكتب الكود.
- من غير لابتوب: افتح من موبايل ← «افتح أوضة» (المضيف بيلعب من موبايله).

وضع التطوير (hot reload): `npm run dev` ثم افتح `http://localhost:5173`.

الاختبارات: `npm test` (اختبارات بروتوكول حقيقية على WebSocket + قواعد الأوضة).

> لو هتجرّب من موبايلات حقيقية: لازم السيرفر يبقى متاح على الشبكة (`http://<IP>:8787`)، والـQR بيتولد من العنوان اللي فاتح بيه الشاشة الكبيرة، فافتح الشاشة الكبيرة بنفس عنوان الـIP مش `localhost`.

## التقنية

- **السيرفر** (`server/`): Node + `ws`. السيرفر هو المسؤول الوحيد عن حالة الأوضة، العشوائية، المؤقتات، النقط، والمشروبات. كل موبايل بياخد «لقطة» خاصة بيه (الأدوار السرية والإجابات مش بتتبعت لحد مش من حقه يشوفها).
- **الواجهة** (`client/`): React + Vite + Tailwind. الأصوات متولدة بالـWebAudio (من غير ملفات صوت). الخطوط: Rubik (عناوين) و Cairo (نص) — مستضافة محليًا.
- **فصل الطبقات**:
  - قواعد كل لعبة: `server/games/*.js` (كل لعبة: `setup / onTick / onInput / isComplete / resolve / view`).
  - واجهة كل لعبة: `client/src/games/*.jsx` (`Phone` و `Big` لكل لعبة).
  - بنك المحتوى: `server/content/*.js` (كل عنصر له `id` ومستوى `min` للشدة).
- مفيش تسجيل دخول ولا قاعدة بيانات: الأوض في الذاكرة وبتتمسح بعد ٣ ساعات من غير نشاط.

## إضافة محتوى أو لعبة

- سؤال جديد: ضيف سطر في الملف المناسب في `server/content/`. استخدم `min: 'medium'` أو `'hardcore'` للحاجات الحرّاقة.
- لعبة جديدة: موديول في `server/games/` + تسجيله في `server/games/index.js` + واجهة في `client/src/games/` وتسجيلها في `client/src/games/index.js`.
