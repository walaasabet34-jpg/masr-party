# سهرة طلقة

لعبة سهرات بالمصري: ٣٠ لعبة صغيرة في بارتي ميكس، وبصرة / الكومي بقواعد مصرية. كل لاعب يدخل من موبايله بالكود أو QR، والمضيف يقدر يلعب من موبايله أو يفتح شاشة كبيرة. فيها شات جماعي لكل أوضة.

## نظام النقط — إصدار 0.2.0

- النقط هي النظام الوحيد. الرصيد ممكن يبقى بالسالب.
- مكافآت الألعاب الحالية محفوظة: ترتيب ٣/٢/١، مبارزات ٢ للمكسب و١ للتعادل، أو مكافأة حسب نتيجة اللعبة. جدول الجولة يعرض التغيير النهائي لكل لاعب.
- الخسارة العادية صفر من غير خصم. الخصم (−١) مع سببه بس في أسوأ الحالات: صاحب القنبلة، الدخيل لو اتمسك، الأكتر أصوات لوحده، الأبطأ في المبارزة أو اللي ضرب بدري، ولا صوت في قفشة/خربشة أو ورقة/إجابة فاضية، والنصّاب اللي محدش اتضحك عليه. التعادل يتحدد بقاعدة اللعبة، وأصحاب نفس أعلى رصيد بيشاركوا لقب البطل.
- الروليت تختار لاعبًا وكارتًا واحدًا: +٢ أو +٣ أو −١ أو −٢. الباقي رصيدهم ثابت.
- المهمة السرية الناجحة: +٢ لصاحب المهمة و−١ للمستهدف، بعد تأكيد المستهدف. التأكيد لا يتكرر.
- الكوتشينة: بصرة / الكومي للاعبين أو ٤ في فريقين، لحد ١٠١ نقطة. ورق كل لاعب مخفي، واللمّ وحساب النقط على السيرفر. قواعد النسخة بالتفصيل في docs/EGYPTIAN-CARDS.md.
- إلغاء الجولة لا يضيف أو يخصم نقطًا. الاستعداد لا يحتاج لأي خطوة تأكيد إضافية.

## التشغيل

Node 20 أو أحدث:

```bash
npm ci --include=dev
npm run build
npm start
```

افتح `http://localhost:8787`. الموبايلات على نفس الشبكة تدخل بعنوان الجهاز أو QR. للعب من أماكن مختلفة استخدم النسخة المنشورة: https://masr-party.onrender.com/

للتطوير: `npm run dev`. للاختبارات: `npm test`.

## النشر

الخدمة الحالية على Render تتبع فرع main. ملف render.yaml موجود في جذر الريبو:

- البناء: `npm ci --include=dev && npm run build`
- التشغيل: `npm start`
- فحص الصحة: `/api/health`، يعرض الإصدار ونظام النقط.
- متغير `PORT` يحدد المنفذ؛ يعمل السيرفر بـWebSocket على `/ws`.
- الأوض والرسائل في ذاكرة عملية واحدة؛ إعادة التشغيل أو النشر يمسح الجلسات. استخدم نسخة تشغيل واحدة.

## الشات

شات نصي لكل أوضة، آخر ٥٠٠ رسالة، ٣٠٠ حرف للرسالة. تحديد المرسل من اتصال السيرفر، ومنع الإغراق وتكرار نفس الرسالة أو إعادة إرسالها بعد انقطاع الاتصال. يرجع سجل الأوضة عند إعادة الاتصال. الشاشة الكبيرة تعرض الرسائل، واللاعبون يكتبون من أجهزتهم.

## بنية المشروع

- `server/room.js`: إدارة الجلسات والجولات والنقط والمهمات.
- `server/games/`: قواعد الألعاب؛ `server/content/`: الأسئلة والمحتوى.
- `server/egyptian.js`: البصرة والكومي وحساب النتيجة؛ `shared/cards.js`: أسماء الورق والتحقق من اللمّ. ملف boat.js القديم محفوظ للمرجع وغير مستخدم في الأوض الجديدة.
- `client/src/screens/`: الشاشات؛ `client/src/games/`: أدوات اللعب.
- `server/test/`: اختبارات النقط والمركب والشات والغرف وبروتوكول WebSocket.

تفاصيل المرجع والفروق في `docs/MATCHING.md`.
